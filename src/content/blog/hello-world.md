This is the first entry. I'm using this space to jot down things I'm building,
problems I've solved, and ideas worth keeping around — short-form, low-effort,
published as I go rather than saved up for a "real" post.

To publish a new one, I run:

```
npm run new-post "Title of the thing"
```

That drops a pre-filled Markdown file into `src/content/blog/`. I write in it,
flip `draft` to `false`, and push — the site rebuilds automatically.
